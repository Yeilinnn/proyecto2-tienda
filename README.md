# Proyecto 2 – Tienda de instrumentos musicales

Tienda en línea hecha con Nuxt y Nuxt Content para el curso de Arquitectura de Información. Tema asignado: tienda de instrumentos musicales ("Tono & Cuerda").

Sitio publicado: https://tonoycuerda.netlify.app/

Qué incluye:
- Catálogo de 36 artículos en 6 categorías, guardados como documentos JSON en `content/`.
- Navegación por categorías, detalle de cada artículo, búsqueda por palabras clave y paginación.
- Carrito de compras con Snipcart (modo de prueba).
- Comentarios por artículo con Utterances (repositorio: https://github.com/Yeilinnn/blog-comentarios).

Para correrlo: `npm install` y luego `npm run dev`.
